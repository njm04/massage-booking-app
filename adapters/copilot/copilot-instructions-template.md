# Repository Instructions

## Scope and precedence
- Follow user request first, then repository instructions.
- Keep changes minimal, safe, and fully complete.

## Required standards
- Include relevant files from `/standards`:
  - common
  - testing
  - security
  - git
  - frontend-react (if frontend)
  - backend-node (if backend)

## Agent routing
- planner: planning-only tasks
- implementer: substantial implementation
- quick-implementer: small scoped updates
- debugger: bug investigation/fixing
- reviewer: read-only review
- documenter: documentation-only work
- git-integrator: commit/push/PR operations when explicitly requested
